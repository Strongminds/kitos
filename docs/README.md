# KITOS documentation

Public-safe technical documentation migrated from the [KITOS Confluence space](https://strongminds.atlassian.net/wiki/spaces/KITOS/overview). The original pages are linked from each document for provenance. Pages that contain operational access details, credential instructions, internal meetings and other private material are deliberately excluded. This is a curated migration, not a complete archive of the space.

- [Technical documentation](technical-documentation/README.md) — architecture, design, guides and development practices.
- [UI requirements](ui-requirements/README.md) — the 2023 UI redesign requirements and data mappings; the frontend itself lives in [kitos_frontend](https://github.com/os2kitos/kitos_frontend).
- [Authorization model](authorization/context-based-authorization-model.md) — context-based authorization.
- [Field-based authorization](authorization/field-based-authorization.md).
- [SwaggerGen tips](tips-for-swaggergen.md).

Screenshots and diagrams are stored as local image assets alongside their migrated documents. Some older documentation may not reflect the current implementation.
