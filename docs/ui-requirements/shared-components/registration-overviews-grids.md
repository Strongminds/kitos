# Registration overviews (grids)

[Original Confluence page](https://strongminds.atlassian.net/wiki/spaces/KITOS/pages/876806199)

This section covers the common requirements shared by all implementations of the grid-based overview of _registrations_ (the main modules)

Module-specific overview requirements are specified in the module-specific descriptions.

* Export to excel

    * visible
    * all

* Auto save

    * Local order
    * Local filtering

* Save/reset

    * Specific filter/query

* Org based (created, updated and/or deleted by a local admin)

    * Order
    * Availability of columns
    * If user diverts from org setup, they get an indication and they can then reset to org setup
