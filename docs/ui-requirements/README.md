# 2023-01-20 - UI Redesign - Requirements sandbox

[Original Confluence page](https://strongminds.atlassian.net/wiki/spaces/KITOS/pages/876773377)

The purpose of this section of the documentation is to capture and communicate UI requirements as well as data-mapping (API) and serve as input to creation of more precise user stories.

We will address the following:

* Read/Write access dependencies
* Data mapping
* Data options mapping (choice types)
* Overviews

    * Fields

        * Order
        * PersistId
        * Name
        * Data source

    * Custom operations

        * filter
        * local admin operations

    * Renderings

        * Cell rendering
        * Excel -specific rendering

    * Excel only fields
    * UI-only fields (e.g. button columns)
    * Data types

        * filtering
        * ordering

    * Customization (data dependencies)

* Role restrictions (which, if any role restrictions exist)
